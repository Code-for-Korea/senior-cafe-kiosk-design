# 카페 키오스크 음성 안내 TTS 요청서

카페 키오스크 화면마다 나오는 안내 음성을 만들어 주세요. 문장은 같은 폴더의 CSV 파일에 있습니다.

| 파일 | 내용 |
|---|---|
| `TTS-문장목록.csv` | 전체 164줄 (모든 화면·오류·안내 창) |
| `TTS-문장목록-성공흐름.csv` | 그중 54줄. 주문해서 카드·현금·휴대폰으로 결제가 되는 길에서 듣는 문장만 |
| `TTS-문장목록-성공흐름.xlsx` | 위 54줄을 단계·화면별로 묶은 보내기용 엑셀. 받는 분이 헷갈리지 않게 파일 이름(이름표) 칸은 뺐고, 번호로 맞춥니다 |

전체가 많으면 **성공흐름 54줄을 먼저** 만들어 주세요. 나중에 전체를 만들 때 이 54줄은 다시 만들지 않아도 됩니다.

## 1. 어떤 음성인가요

| 항목 | 요청 |
|---|---|
| 듣는 사람 | 카페 키오스크를 쓰는 어르신. 화면을 보면서 듣습니다 |
| 목소리 | 여성 |
| 말투 | 차분하고 또박또박한 안내 말투 |
| 빠르기 | 보통 |
| 문장 | 글자 그대로 읽어 주세요. 쉼표에서는 짧게 쉬어 주세요 |

## 2. 만드는 법

- CSV의 한 줄을 파일 하나로 만들어 주세요.
- 파일 이름은 편하신 대로 해 주세요. `번호` 칸의 번호(예: `01.mp3`)나 문장 그대로여도 됩니다. 저희가 맞춰 바꿉니다.
- `쓰는 곳` 칸은 그 음성이 나오는 화면입니다.
- 파일은 mp3로, 앞뒤 무음은 짧게(0.1초 이하) 해 주세요. 화면에서 여러 파일을 이어서 틀기 때문입니다.
- 목록을 한 번에 넣어 만들 수 있는 도구가 있으면 그렇게 해 주세요. 문장이 바뀌면 같은 방식으로 다시 만들 수 있습니다.
